# JoysList

JoysList is a Craigslist-inspired marketplace application built as a full-stack microservices project.

The goal of this project is to gain hands-on experience across the entire software development lifecycle, including frontend development, backend development, distributed systems, containerization, and deployment.

## Project Goals

This project is being built to explore:

* Frontend development with modern web technologies
* Backend development using Spring Boot
* Microservices architecture
* API Gateway and service discovery
* Authentication and authorization
* Database design
* Docker and containerized deployments
* CI/CD and DevOps practices
* Cloud deployment
